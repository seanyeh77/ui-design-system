用 Docker 打包你的第一個服務

這篇從零開始，帶你把一個 Python 網頁服務包成 image，再用 docker compose 在 3 台節點上執行。

Background

容器 (container) 是一個與主機隔離的執行環境。它和虛擬機器不同，不需要完整的作業系統，所以啟動時間通常在 1 s 以內，記憶體用量也只有幾十 MB。

Image 與 Container

Image 是唯讀的模板，container 是 image 執行起來的實例。同一個 image 可以同時跑很多個 container。
