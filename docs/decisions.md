# 定案紀錄

設計畫布上每個實驗室最後選定的設定，照當時的原文記錄。寫著「看情況」的項目不是固定規則，依使用情境決定。完整的規則整理在 [設計規則](guidelines.md)。

## 整體

- 中性色用暖灰，強調色 `#2457d6`（可以換）。字體 Inter 加思源黑體（Noto Sans TC），數字用 Geist Mono。
- 後台頁面用側邊欄加頂部列；收合鈕在左下角，只有圖示。
- 不使用原生 `<select>`。
- 欄位排列依螢幕寬度：960 px 以上排兩欄。
- 標題不換行。
