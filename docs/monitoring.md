# 監控畫面

全螢幕、常駐、遠看的監控畫面（例如機房）。一般後台頁用 AppShell，不用這份。

## 版面

- 用 `ConsoleLayout`：頂列左邊標題和「示範資料」，右邊狀態、KPI、時間、全螢幕按鈕；主視覺在左、側欄在右、圖表在主視覺下方；整頁不捲動，放不下時側欄自己捲動；螢幕夠高才多出的卡片加在側欄最後面；手機排成一欄的長頁。
- 字級：最小字 13 px，SVG 軸標 12 px。大螢幕依視窗等比放大：倍數 = 視窗寬 ÷ 1440 和 視窗高 ÷ 900 的較小者，下限 1、上限 1.5；1440 × 900 以下不縮小，改用斷點。
- 頂列的 KPI 用 `KpiCard size="compact"`：數字 22 px，一行灰字目標；判定只在需要注意時取代目標那一行，用文字和狀態色，不加符號、不加底色。
- 頂列的「示範資料」和狀態文字（例如「AI 最佳化中」）和旁邊的字同樣大小、同樣顏色，不另外上色。
- 危險動作照一般規則：按鈕用實心紅色，按下後先跳確認對話框（例如「切回 PID 控制？」）；不用卡片內的行內確認，也沒有紅色外框的按鈕。

## 元件

| 用途 | 元件 |
|---|---|
| 分區平面圖，依數值填熱度色 | `ZoneMap`（名稱 16 px 和狀態同一行，主數值 31 px，次要資訊 13 px） |
| 事件列表，由新到舊 | `EventTimeline`（時間、類型圖示、說明） |
| 時鐘、回放、回到現在 | `TimeControl`（直排，時鐘 28 px） |
| 預測與實際、節能的折線 | `LineChart`（`dashed`、`band`、`now`、`thresholds`、`marker`、`playhead`、`headline`） |
| 沿時間軸的狀態色帶 | `StatusBand`（12 px，貼在折線圖底部，名稱寫在圖例） |
| 數值和注意線、上限 | `Meter` |

## 圖表

- 預測與實際的圖：實際是實線，預測是虛線（`chart-3`）；「現在」是一條實線，之後的未來區疊預測斜線；注意線和上限是 1.5 px 的 `warning`／`danger` 虛線，標籤靠右寫在線上方；下一回合的單點預測是空心圓加標籤。
- 差額帶：預測與實際依正負填 `diverge-pos`／`diverge-neg` 30%，實際與基準之間（省下的量）填 `success` 28%；不用在三組以上的圖。
- 回放：播放頭是強調色 2 px 線，x 軸上一個 16 px 圓形把手；在圖上按下拖曳，或 Tab 到圖上後 ← → Home End 移動。
- 節能這類總結數字（「省 186 kWh（約 12%）」）放在圖的上方（`headline`，25 px），不疊在圖上；來源說明寫在圖下方一行。
- 預測值的區塊疊斜線並加「預測」標籤；整頁示範值加「示範資料」（見 [data.md](data.md)）。
