# 版面架構

依使用情境選擇兩種架構之一。

## Dashboard 類

- 側邊欄加頂部列。
- 側邊欄可收合：展開 240 px（`sidebar-width`），收合 72 px（`sidebar-collapsed`）。
- 收合按鈕在側邊欄左下角，只有圖示、沒有文字。

## 展示類

- 只用頂部導覽。

## 共通規則

- 內容最大寬度：滿版。
- 格線：12 欄。
- 卡片排列：均等格線。
- 區塊間距：緊密 32 px（`space-8`）。
- 手機導覽：底部分頁列。
- 頁首行為：往下捲時隱藏，往上捲時出現。
- 頁尾：精簡一行。

## 斷點

| 名稱 | 寬度 (px) | Token |
|---|---|---|
| 手機 | 0 到 599 | 小於 `bp-tablet` |
| 平板 | 600 到 959 | `bp-tablet` |
| 桌面 | 960 到 1279 | `bp-desktop` |
| 大螢幕 | 1280 以上 | `bp-wide` |

- 600 到 1024 px 時，Dashboard 類沒有側邊欄，頂部列左邊的選單按鈕打開導覽抽屜。
- 表單欄位：`bp-desktop`（960 px）以上雙欄，以下單欄。
