# 版面與導覽

依使用情境選擇兩種架構之一。頁面外框用元件就好（`AppShell`、`ConsoleLayout`、`Workbench`）；這份給要自己排外框、導覽或說明的頁面。

## Dashboard 類

- 側邊欄加頂部列（`AppShell`）。
- 側邊欄預設不釘選：平常是 72 px 的圖示列（`sidebar-collapsed`），滑鼠停在上面或用 Tab 移進去時展開成 240 px（`sidebar-width`），疊在內容上，離開後收回。
- 左下角的圖釘按鈕釘選側邊欄，釘選後固定在內容旁邊，可以收合成 72 px；圖釘和收合按鈕都只有圖示、沒有文字。
- 主要區域旁邊的側邊面板（程式碼、詳細資料）要能調整寬度時用 `SplitPane`：中間的分隔線有一個小把手，可以拖拉、用方向鍵移動，雙擊回到預設寬度；寬度小於 960 px 時上下排列。

## 展示類

- 只用頂部導覽。

## 共通規則

- 內容最大寬度：滿版。
- 格線：12 欄。
- 卡片排列：均等格線（`Grid`）。
- 區塊間距：緊密 32 px（`space-8`）。
- 手機導覽：底部分頁列。
- 頁首行為：往下捲時隱藏，往上捲時出現。
- 頁尾：精簡一行。

## 斷點

| 名稱 | 寬度 (px) | Token |
|---|---|---|
| 手機 | 0 到 599 | 小於 `bp-tablet` |
| 平板 | 600 到 959 | `bp-tablet` |
| 桌面 | 960 到 1279 | `bp-desktop` |
| 大螢幕 | 1280 以上 | `bp-wide` |

- 600 到 1024 px 時，Dashboard 類沒有側邊欄，頂部列左邊的選單按鈕打開導覽抽屜。
- 表單欄位：`bp-desktop`（960 px）以上雙欄，以下單欄。

## 導覽

各元件的細節見它的 README；這裡是整頁要一致的部分。

- 側邊欄（`SideNav`，AppShell 內建）：選中用左側指示條（水滴方式移動）；滑過灰底；項目高 40 px；組與組之間分隔線；收合後滑過顯示名稱提示；子選單展開縮排。品牌用 `brand={{ mark, name, href }}`，只有文字時用第一個字放在強調色方塊裡當 logo。
- 頂部列（`TopBar`）：左邊頁面標題，右邊填色搜尋框（附 Ctrl K 提示，Mac 上寫 ⌘K）；手機上搜尋框換成搜尋圖示。麵包屑放在內容區最上方，不放在頂部列。
- 麵包屑（`Breadcrumb`）：箭頭「›」分隔，一般字。
- 同一頁裡切換檢視：分段控制（`Tabs`），水滴動畫，內容依序浮起；分段上的數字帶單位。例外是 DataTable 的狀態摘要：整排同一個單位，畫面上只寫數字，單位給螢幕閱讀器（`hideUnit`）。
- 手機底部分頁列（`MobileTabBar`，AppShell 內建）：每個圖示下方一行 12 px 文字，選中時圖示後方出現膠囊；放不下的頁面放在最後一格「更多」。
- 專案狀態：頂部列右邊放 `ProjectSwitcher`，外框 Chip 寫「專案 · 即時」，圓點表示資料狀態。
- 通知：頂部列的 `NotificationBell`。主題與強調色放在設定頁的「外觀」，不放在頂部列。

## 搜尋與說明

- 搜尋：`CommandPalette`，一個搜尋找全部（頁面、設定、指令、檔案，以及專案自己的種類）。任何頁面按 Ctrl K（Mac 是 ⌘K）都能打開，入口是頂部列的搜尋框。
- 第一次使用的導覽：`Tour` 加 `useTour(key)` 記住看過了沒有。可以略過，看完或略過後不再自動出現；頁面上要有「重看導覽」。有「導覽」按鈕的頁面不自動打開，改在按鈕上提示（`IconButton` 的 `hint`）；不用「第一次使用」橫幅。
- 讀者可能看不懂的名詞和關係標籤：`Term`；句子裡用 `variant="inline"`。
- 發現寫錯的地方：`Suggestion`，舊的和新的上下兩行，可以複製修正。
- 頁面範本：錯誤頁 `ErrorPage`、登入頁 `LoginCard`、設定頁 `SettingsLayout`（改完自動儲存，危險操作放最下方的 `DangerZone`）。
