# 動畫

元件已經有自己的動畫；這份給自己做動畫的頁面，時間和曲線用下表的 token，不寫死數字。動畫程度：細緻回饋、轉場，以及吸睛的進場效果。

## 時間

| 用途 | 時間 (ms) | Token |
|---|---|---|
| 滑過、按下、顏色變化；彈出框和遮罩淡入 | 150 | `--dur-hover` |
| 「⋯」選單從按鈕所在的角落放大 | 180 | `--dur-menu` |
| 分頁、分段控制、開關、側邊欄的指示塊（水滴：前端 120 ms、後端 440 ms） | 200 | `--dur-nav`（元件用 `dropTransition()`） |
| 內容進場：卡片依序浮起，每張間隔 40 ms | 200 | `--dur-nav`、class `ui-rise-in` |
| 提示從箭頭那一側放大，稍微回彈 | 220 | `--dur-tooltip` |
| 段落展開與收合（Section）、樹狀清單子項目 | 260 | `--dur-expand` |
| 切換主題時所有顏色漸變；抽屜滑出與遮罩 | 300 | `--dur-toggle` |
| 抽屜彈性滑入 | 450 | `--dur-drawer` |
| 長條由下長高，每根間隔 40 ms | 500 | `--dur-bar` |
| 折線依序畫出（每條間隔 150 ms）；KPI 數字和達成率圓環從 0 數上來 | 900 | `--dur-chart` |
| 不確定進度的水滴，一輪 | 1400 | `--dur-loop` |

- 彈出框（Popover）滑鼠移開 150 ms 後關閉；提示（Tooltip）0 ms 延遲。
- 表格排序：留在本頁的列依序滑到新位置，每列 320 ms、由上往下間隔 25 ms，`--ease-standard`；換頁時整頁往上滑出、新頁從下方滑入，上一頁相反（DataTable 內建）。

## 曲線

| 用途 | Token |
|---|---|
| 預設：進場、停下來 | `--ease-standard` |
| 指示塊和面板在兩個位置之間滑動 | `--ease-glide` |
| 稍微回彈：提示、浮起的卡片、抽屜滑入 | `--ease-spring` |
| 離開：抽屜和側邊面板滑出 | `--ease-exit` |

## 水滴

分頁、分段控制、開關、側邊欄和手機分頁列的選中指示都是同一塊：靠近目標的一端先動（120 ms），另一端慢 2.2 倍才跟上（440 ms），移動中略為變細，停下來是清晰的圓角矩形（`radius-md` 10 px）。

## 減少動態效果

使用者在系統開啟「減少動態效果」（`prefers-reduced-motion: reduce`）時，只保留淡入淡出，關閉位移與縮放：數字直接顯示最終值，圖表只淡入，水滴載入條改成靜止的半透明條，`ui-rise-in` 改成 150 ms 淡入。
