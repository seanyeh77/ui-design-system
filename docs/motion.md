# 動畫

動畫程度：Level 3（細緻回饋、轉場，以及吸睛的進場效果）。

| 用途 | 時間 (ms) |
|---|---|
| hover、按下 | 150 |
| 分頁、開關、提示 | 300 |
| 主題切換 | 350 |
| 進場（逐項間隔 90） | 700 |
| 段落展開與收合（Section）、樹狀清單子項目 | 260 |

## 導覽切換

| 項目 | 設定 |
|---|---|
| 動畫時間 | 200 ms |
| 拉伸程度 | 明顯：後端比前端慢 2.2 倍（前端 120 ms、後端 440 ms） |
| 停下來的形狀 | 圓角矩形（`radius-md` 10 px） |
| 停下來的邊緣 | 清晰 |
| 分頁指示 | 水滴：同一塊拉長再收回，移動中略為變細 |
| 側邊欄選中 | 水滴：指示條拉長移動再收回 |
| 內容切換 | 卡片依序浮起，間隔 40 ms |
| 手機分頁切換 | 水滴膠囊 |

## 數據呈現

| 項目 | 設定 |
|---|---|
| KPI 數字 | 從 0 數上來，900 ms，ease-out |
| 折線 | 依序畫出，每條 900 ms，間隔 150 ms |
| 長條 | 依序由下長高，每根 500 ms，間隔 40 ms |
| 達成率圓環 | 和數字一起從 0 跑到目標值，900 ms |
| 不確定進度 | 水滴：1.4 s 一輪，前端用 ease-out、後端用 ease-in-out，所以中間會拉長 |

## 浮層

| 項目 | 設定 |
|---|---|
| 提示 | 0 ms 延遲；從箭頭那一側放大，220 ms，稍微回彈 |
| 「⋯」選單 | 從按鈕所在的角落放大，180 ms |
| 彈出框 | 淡入 150 ms；滑鼠移開 150 ms 後關閉 |
| 側邊抽屜 | 彈性滑入 450 ms；滑出 300 ms；遮罩淡入 300 ms |

## 外觀

| 項目 | 設定 |
|---|---|
| 切換主題 | 所有顏色漸變 300 ms |

## 表格

| 項目 | 設定 |
|---|---|
| 排序 | 依序滑動：每列 320 ms，由上往下間隔 25 ms，ease-out |
| 還原排序 | 和排序相同 |
| 換到別頁的列 | 換出的往下滑出並淡出，換進的從下方滑入並淡入 |
| 換頁 | 下一頁整頁往上滑出、新頁從下方滑入；上一頁相反 |

## 減少動態效果

使用者在系統開啟「減少動態效果」（`prefers-reduced-motion: reduce`）時，只保留淡入淡出，關閉位移與縮放。

- 數據呈現：數字直接顯示最終值，圖表只淡入，水滴載入條改成靜止的半透明條。
