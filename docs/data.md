# 表格、清單與圖表

細節在各元件的 README；這裡是選哪個元件，以及跨元件要一致的規則。

## 選哪個元件

| 要呈現的 | 元件 |
|---|---|
| 有欄位的資料，要排序、篩選、分頁 | `DataTable`（放在 `Card` 裡時標題寫在 Card 的 `title`，DataTable 給 `label`） |
| 資料夾與檔案、可以展開的階層 | `TreeList`；不是檔案的階層（呼叫關係）用 `kind="plain"` |
| 一個項目的詳細欄位 | `DetailList` |
| 可以收合的段落 | `Section`，一組用 `SectionGroup` |
| 卡片上的多個操作 | `ActionBar` |
| 重點數字 | `KpiCard` |
| 趨勢 | `LineChart` |
| 類別比較 | `BarChart` |
| 知道進度 | `ProgressBar`；不知道要多久用 `LoadingBar`；達成率用 `ProgressRing` |
| 數值和它的界線 | `Meter` |
| 依數值上色的平面圖 | `ZoneMap` |
| 元件架構 | `LayerGraph`；其他方框與箭頭的圖用 Graph 的 class |

## 表格與結果清單

- 數字欄給 `numeric: true` 加 `unit`，資料是數字，不是帶單位的字串（「46 分」不能排序也不能加總）；表格裡的數字不縮寫。時間長度用 `format: 'duration'`，日期用 `date`、`relative`。
- 狀態欄用 Badge，不自己做彩色標籤。
- 合計列、固定第一欄、常用檢視、同一欄位多選：看情況，依資料決定要不要開。
- 結果清單（檢查結果、審核清單）：上方用分段控制當摘要（全部加各狀態，附筆數），點了就篩選（DataTable `summary`）。摘要上的筆數只寫數字（「錯誤 4」），單位給螢幕閱讀器念（「錯誤 4 筆」）：同一排的單位都一樣，寫出來只是雜訊。要處理的狀態（失敗）緊接在「全部」後面。排序看情況，預設照資料原本的順序。
- 同一個條件只在一個地方：摘要已經有的欄位不再放進「篩選」。摘要已經寫出各狀態的筆數，就不用 KPI 卡片重複；KPI 只放表格看不出來的數字（總時數、成功率、趨勢）。
- 失敗的列寫出原因，並提供「重試」：列上一個，勾選後的批次操作一個。執行中的列把進度寫在欄位的次要文字（`secondary`，例如「匯入中 42%」），格子裡不放 ProgressBar。
- 工具列是一個完整的結構：摘要分段、搜尋、「篩選」「排序」「⋯」和主要操作（「新增」，DataTable 的 `action`）放得下時同一列，摘要靠左、其他靠右；放不下時摘要自己一列。
- 列操作（`rowActions`）不占一欄：滑鼠滑過或鍵盤移到列上時出現在列的右端，最後一格右邊留好它的寬度，不蓋到任何內容；觸控螢幕和手機卡片一直顯示。超過 2 個時，其餘收進「⋯」選單。打開一筆資料用 `rowHref`（整列是連結），不另外放「查看」按鈕；SPA 用 `onRowOpen` 推路由。
- 欄寬：第一個文字欄占剩下的寬度，數字、單位、日期、長度和狀態欄貼合內容。`width` 只是最小寬度，不決定哪一欄占剩下的寬度。短的文字欄（人名、2 到 6 個字）最窄 128 px；長文字欄（`long`）和主要欄各分一份，不會吃掉整張表；日期和數字一行放得下，不截斷。沒有內容的格子是灰色的「—」（`ink-muted`）。
- 字體：數字用 Geist Mono，單位、相對時間（「5 分鐘前」）和其他中文用一般字體加等寬數字。
- 階層清單的排序、展開方式（一次全部或一次一個）和勾選：看情況，見 TreeList。

## 數字與圖表

- KPI 卡片：標籤、大數字、迷你折線（近期趨勢）、和上一期比的變化。變化用箭頭加彩色文字，後面接灰色「較上週」；顏色看好壞、不看方向：例如回應時間下降是好事，用綠色。
- 圖表配色：多色，依序 `chart-1` 藍、`chart-2` 青、`chart-3` 橘、`chart-4` 暖灰；只有一組資料時用 `chart-1`；`chart-4` 給「其他」「人工」這類次要的一類。類別超過 3 時，圖例一定有文字，色帶旁有標籤。
- 熱度色階 `heat-1`…`heat-7`（冷 → 熱，藍 → 中性暖灰 → 橘紅）與差值的發散色階（負藍、0 灰、正橘）只用在資料的填色；上面的字用 `textOn(fill)`。狀態不只靠顏色：數值一定寫出來，告警加「⚠」文字與邊框。見 DataColors。
- 預測、非實測的數值：填色上疊斜線（`ui-forecast`），旁邊加 `Tag variant="forecast"`「預測」。整頁都是示範值時，頂列品牌旁放一個 `Tag variant="demo"`「示範資料」。
- 折線：平滑曲線，不填色；唯一的例外是兩組資料之間的差額帶（LineChart `band`）。長條：頂部 4 px 圓角。
- 格線：淡色虛線（`line`）；底線用實線。
- 數值提示：滑過時出現浮起卡片（`surface` 加 `shadow-overlay`），折線圖同時顯示垂直參考線和各組的點。
- 圖表進場：依序長出，折線一條接一條（間隔 150 ms），長條一根接一根（間隔 40 ms）；數字從 0 數上來（900 ms）。
- 進度條：8 px，百分比寫在條的下方；到 100% 時變成功綠色，文字變「完成 ✓」。不知道要多久時用水滴載入條，和導覽動畫一致。達成率用圓環，中間放百分比。
