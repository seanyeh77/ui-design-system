# 閱讀程式碼的工具

給讀程式碼、看架構、看專案文件的工具頁（例如程式碼瀏覽器、架構說明網站）。細節在各元件的 README。

## 選哪個元件

| 要呈現的 | 元件 |
|---|---|
| 整頁：檔案總管、主畫面、右側欄、下方面板，像 VS Code | `Workbench` |
| 主要區域旁邊可以調寬的面板 | `SplitPane` |
| 有行號的程式碼 | `CodeView`；外層已經寫出檔名時（例如 Workbench 的麵包屑）用 `header="float"` |
| 元件架構圖 | `LayerGraph`；其他方框與箭頭的圖用 Graph 的 class 加 `GraphDefs`、`GraphLegend` |
| 檔案總管、大綱、呼叫關係 | `TreeList kind="plain"`，檔案總管和側欄的大綱加 `density="compact"` |
| 專案文件、程式註解 | `Markdown`；.md 檔的「預覽／原始碼」用 `SegmentedControl` 切換 |
| 句子裡的名稱和位置 | `InlineCode look="name"`（函式、類別、變數）、`look="location"`（檔案和行號） |
| 讀者可能看不懂的名詞 | `Term`；同一份程式碼或文件反覆出現的，用 CodeView 或 Markdown 的 `terms` |
| 一個項目的詳細欄位 | `DetailList` |
| 可以收合的段落 | `Section` |
| 修正建議 | `Suggestion` |

## 共通規則

- 名稱和位置都一定指向某個地方（是連結）；不指向任何地方的維持灰底的行內程式碼。
- 程式碼裡的名稱連結保留語法色，按住 Ctrl 或 ⌘ 時才可點（一般點擊選取文字，觸控螢幕點一下就開）。
- AI 寫的內容最後加 `AiMark`；沒有標示的代表來自程式碼或語言規則。推測的關係用細虛線和「推測」標籤，專案宣告的關係用長短交替的虛線。
- 標籤只標例外：大部分項目都一樣的屬性不標，只標需要留意的，用 Tag 包 Term；預設值在下方說明一次（例如沒有標示的關係都由編譯器確認，只標「推測（規則）」）。
- 分類標籤（「外部」、「範本」、「推測」）用 `Tag`；進度或結果用 Badge。
- 架構圖放在卡片上；比外框寬時先縮窄方框、再整張縮小，還放不下才左右捲動，右緣有漸層，下方有捲動提示，捲動位置會記住。程式碼太長的行自動換行，不橫向捲動。
