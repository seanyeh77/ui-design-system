# BarChart

## 用法

長條圖（單組資料），比較幾個類別的數值。看趨勢用 LineChart。

```tsx
<BarChart
  label="各區域的請求數"
  unit="次"
  data={[
    { label: '台北', value: 1280 },
    { label: '台中', value: 864 },
  ]}
/>
```

- `label` 必填，是圖表的無障礙名稱；`unit` 寫在數值後面，也寫在 y 軸上方（13 px 以下的 `ink-muted` 小字）。
- 數值上萬時給 `format="compact"`：軸和數值卡片寫「50 萬」「1.5 億」（英文 1.5M），不寫「1,500,000」。不給時 y 軸的寬度也會依標籤量，不會畫到卡片外。
- 和旁邊較高的卡片並排時給 `height="fill"`：長條區填滿 Card 剩下的高度（最矮 160 px），不留空白；預設 200 px，也可以給數字（px）。等寬的 Grid 一排本來就一樣高；比例 Grid（`columns={[2, 1]}`）靠上對齊，要撐滿時那個 Grid 給 `align="stretch"`。
- 顏色 `chart-1`，柱子頂部 4 px 圓角，間距 8 px。滑過或用鍵盤移到柱子時，上方浮起卡片顯示數值。

## 細節

- 格線為淡色虛線；滑過時其他柱子變淡。
- y 軸刻度是 1、2 或 5 乘 10 的次方（不會出現 12.5、37.5），3 到 5 格，最上面一格是第一個大於等於最大值的刻度（最大 128 萬時軸到 150 萬，不到 200 萬）。數值有小數（`decimals`）或範圍小於 3 時才有小數刻度。給 `max` 時軸的上限是 `max`，整除不了時平分 4 格。
- y 軸的寬度量的是實際畫出的刻度文字（字型晚載入、讀者加大字距時重新量）。
- 鍵盤：圖可以用 Tab 移到（有 2 px `focus` 外框），← → 在柱子之間移動、Home／End 到第一根／最後一根，和滑過一樣顯示數值卡片，螢幕閱讀器念「名稱：數值 單位」。圖是 `role="application"`（`aria-roledescription`「長條圖」），讓螢幕閱讀器把方向鍵交給圖；同樣的數值也在圖後面一個只給螢幕閱讀器的表格裡（第一欄項目、第二欄數值），用一般的表格瀏覽方式就能讀。
- 進場時一根接一根長高，間隔 40 ms。
