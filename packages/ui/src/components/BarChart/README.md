# BarChart

## 用法

長條圖（單組資料），比較幾個類別的數值。看趨勢用 LineChart。

```tsx
<BarChart
  label="各區域的請求數"
  unit="次"
  data={[
    { label: '台北', value: 1280 },
    { label: '台中', value: 864 },
  ]}
/>
```

- `label` 必填，是圖表的無障礙名稱；`unit` 寫在數值後面。
- 顏色 `chart-1`，柱子頂部 4 px 圓角，間距 8 px。
- 滑過或用鍵盤移到柱子時，上方浮起卡片顯示數值。

## 細節

- 格線為淡色虛線；滑過時其他柱子變淡。
- 鍵盤：圖可以用 Tab 移到（有強調色焦點框），← → 在柱子之間移動、Home／End 到第一根／最後一根，和滑過一樣顯示數值卡片，螢幕閱讀器念「名稱：數值 單位」。
- 進場時一根接一根長高，間隔 40 ms。
