# DataTable

資料表格，有排序、勾選、篩選和分頁。

## 外觀

- 表頭：灰底（`surface-sub`）粗體 14 px，往下捲動時固定在上方。
- 列高 48 px。
- 分隔：斑馬紋加格線。偶數列用 `surface-sub`，每列之間有橫線，欄之間有直線，外圍有框，全部用 `line`。
- 滑過列：整列變成強調淺底 `accent-soft`；勾選中的列也用 `accent-soft`。
- 數字欄 `numeric: true`：Geist Mono、等寬數字、靠右對齊。
- 單位寫在每格數字後面：欄位設定 `unit`，例如 `unit: 'GB'` 會顯示「3,480.3 GB」。表格裡的數字不縮寫。
- 欄位格式 `format`：`money`（NT$ 1,280,000）、`date`（2026/11/04（三））、`datetime`、`relative`（一週內寫「2 小時前」）、`percent`（一位小數，% 用 `unit: '%'` 加上，和 KpiCard 一樣）。
- 狀態欄使用 Badge。
- 欄位標題不換行；欄寬至少要放得下標題和排序箭頭（`width` 設最小寬度），放不下時表格橫向捲動，底色延伸到最右邊。容器比表格窄時（例如旁邊開著詳細面板），右邊還有欄位時右緣有漸層，表格下方靠右有提示，觸控螢幕寫「→ 左右滑動」、滑鼠寫「→ 向右捲動」；第一次左右捲動後提示隱藏但保留位置，捲到最右邊時漸層消失。看的是表格自己的寬度，不是視窗寬度。

## 排序

- 點欄位標題排序。第一下：文字欄從小到大，數字欄從大到小；第二下：反過來；第三下：還原成原本的順序。
- 排序箭頭滑過標題才顯示；正在排序的欄位一直顯示箭頭，標題變成 `accent-text`。
- 不能排序的欄位設 `sortable: false`；排序依據和顯示內容不同時用 `sortValue`。

## 勾選與操作

- `selectable`：勾選框平常隱藏，滑過列（或用鍵盤移到列上）才出現；勾了任一筆後所有列都顯示。觸控裝置一直顯示。
- 勾選後，表頭換成批次操作列：全選框、「已選 n 筆」、`bulkActions` 的按鈕、取消選取 ×。
- 篩選、搜尋、檢視或摘要改變後看不到的列會自動取消勾選，刪除的列也一樣，所以 `bulkActions` 只處理畫面上留下的列（換頁不影響）。
- 單筆操作 `rowActions`：放 IconButton，滑過列時出現在最右邊（例如編輯、刪除）。刪除一樣要先跳確認對話框。

## 搜尋與篩選

- 搜尋框搜所有欄位，符合的文字用黃底標出（`mark`）。只想搜部分欄位時用 `search.keys`；用 `render` 的欄位提供 `searchText`。
- 篩選：搜尋框旁邊的「篩選」按鈕，按鈕上顯示已套用的條件數。點開是彈出框，`filters` 裡的每個欄位一區：
  - `type: 'list'`：勾選清單，每個選項後面寫套用後會剩幾筆；沒給 `options` 時從資料取出。
  - `type: 'range'`：最低、最高兩個欄位；`scale` 是輸入單位（例如 10000 代表「萬」），`unitLabel` 寫在下方。
- 勾選就生效，不需要「套用」按鈕。彈出框右上角有「清除全部」。
- 搜尋框右邊顯示「10 / 24 筆」。
- 沒有結果時顯示一句話，再加「清除篩選」按鈕。
- 條件寫進網址（`?status=doing,review&q=…`），重新整理或分享連結時保留；同一頁有兩個表格時用 `urlKey` 分開；`urlSync={false}` 關掉。
- 換成另一份資料（例如切換專案）時，給新的 `resetKey`：搜尋、篩選、排序、頁碼、勾選和摘要都回到預設。只換內容、條件要保留時不用給。
- 分頁：頁碼，每頁 10 筆（`pageSize`），左下顯示「第 1–10 筆，共 24 筆」。只有一頁時不顯示這一行和頁碼：右上的「6 / 6 筆」已經寫了筆數，同一件事只說一次。

## 看情況決定的功能

這幾項沒有固定規定，依資料決定要不要開：

- 同一欄位能不能選多個：預設可以（`multiple: true`），選項互斥時（例如「本月／上個月」）設 `multiple: false`。
- 合計列 `totals`：有金額或數量需要加總時才開，例如 `{ budget: 'sum', progress: 'avg' }`；第一欄自動寫「合計 n 筆」。
- 固定第一欄 `stickyFirst`：欄位多、常需要橫向捲動時才開。
- 常用檢視 `views`：有幾組固定的看法（例如「我負責的」、「本週到期」）時才開，表格上方變成分頁，旁邊寫筆數。

## 欄位顯示

- 工具列右邊的「欄位」按鈕可以隱藏或顯示欄位，第一欄不能隱藏。`columnMenu={false}` 關掉。

## 動畫

- 排序：留在本頁的列由上往下依序滑到新位置，每列 320 ms，間隔 25 ms；底色跟著從舊位置的顏色轉成新位置的顏色。還原（第三下）用同樣的動畫。
- 排序後被換到其他頁的列往下滑出並淡出，從其他頁換進來的列從下方滑上來並淡入。
- 換頁：下一頁時整頁往上滑出、新的一頁從下方滑進來；上一頁相反。
- 減少動態效果時不播放這些動畫。

## 結果摘要

- `summary={{ key, items: [{ value, label }] }}`：表格上方放一個分段控制（Tabs），「全部」加上每種狀態，各自附筆數，點了就只看那一種。筆數後面帶單位，預設「筆」，用 `summary.unit` 換成「則」「個」等。用在檢查結果、審核清單這類有狀態的清單。
- 排序看情況：結果清單預設照資料原本的順序（例如筆記的行號），不自動把錯誤排到前面；需要處理的項目用摘要篩選出來。

## 手機

- 寬度小於 600 px 時，所有列放在同一張卡片裡，列與列之間用分隔線。
- 每一列：第一行是標題列，左邊是標題欄位，右邊是狀態欄位，最右邊是操作按鈕（`rowActions`）；其他欄位往下堆疊，欄位名稱在上（12 px 次要文字）、值在下，全部靠左，欄位之間 4 px。
- 欄位用 `mobile` 指定：`'title'`（標題列左邊，預設是第一欄）、`'status'`（標題列右邊）、`'hide'`（手機不顯示）。
- 長文字欄位設 `long: true`：卡片上最多 2 行，超過時下方出現「顯示全部」；桌機時一行，超過用「…」，滑過或用 Tab 移到被截掉的格子時，上方的 Tooltip 顯示全文（最寬 360 px，自動換行）。沒被截掉的格子沒有 Tooltip，也不會被 Tab 移到。
- 卡片裡的 Badge 自動改成「圓點加文字」：沒有底色和陰影，文字用該狀態的文字色。
- 勾選框在標題列最左邊，一直顯示；操作按鈕一直顯示，不用滑過。
- 工具列維持一行：搜尋框佔剩下的寬度，接著「篩選」和筆數；「欄位」按鈕在手機上不顯示。
- 筆數和頁碼文字只有數字用 Geist Mono，「筆」等文字用一般字體；有單位的數字欄也一樣（「1 層」）。

## 無障礙

- 搜尋、篩選、摘要或檢視改變後，live region 念「顯示 6 筆」。
