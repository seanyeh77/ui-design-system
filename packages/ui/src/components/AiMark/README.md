# AiMark

標出 AI 寫的段落：段落開頭一個小的「AI」。

- 10 px 粗體、`ink-muted` 灰字，1 px `line` 框線，4 px 圓角，左右 4 px 內距，和後面的文字隔 6 px。
- 放在段落、清單項目或表格格子的開頭。取代句尾的「（AI 說明）」。
- 不是連結也不是按鈕，Tab 不會停在上面。
- 畫面上的「AI」對螢幕閱讀器隱藏，改念「AI 說明：」。`label` 可以換成別的說法（例如英文介面的 `'AI note'`；沒給時跟著 `UI.t()` 的語言）。
- 在 Markdown 裡寫 `[AI](ai:)`，`UI.Markdown` 會畫成這個標記。

```tsx
<p>
  <AiMark />
  這個函式在每次路由表變動時重新建立連線，所以第 540 行的呼叫次數會隨鄰居數增加。
</p>
```

```md
[AI](ai:) 這個函式在每次路由表變動時重新建立連線。
```
