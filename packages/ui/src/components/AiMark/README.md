# AiMark

標出 AI 寫的文字：在句子、段落、清單項目或表格格子的最後，用灰色小字寫「AI 撰寫」。

- 13 px、`ink-muted` 灰字，和前面的文字隔 8 px，不換行。
- 放在最後，和其他來源標示（例如「推測」）同一個樣子：`text` 可以換字，`<AiMark text="推測" />`。沒有標示的代表來自程式碼或語言規則。
- 不是連結也不是按鈕，Tab 不會停在上面。
- 畫面上的字對螢幕閱讀器隱藏，改念「（AI 撰寫）」；`label` 可以另外指定（沒給時跟著 `UI.t()` 的語言）。
- 在 Markdown 裡寫 `[AI](ai:)`，`UI.Markdown` 會在那一段（段落、清單項目或表格格子）的最後畫這個標示；寫在開頭或結尾都可以。`[推測](ai:)` 顯示「推測」。

```tsx
<p>
  這個函式在每次路由表變動時重新建立連線，所以第 540 行的呼叫次數會隨鄰居數增加。
  <AiMark />
</p>
```

```md
這個函式在每次路由表變動時重新建立連線。[AI](ai:)
```
