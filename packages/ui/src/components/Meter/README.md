# Meter

一個數值和它的界線：8 px 的條分成正常、注意、超過上限三段淡色，圓點標出目前值，上方寫出數值和狀態。

- 條：正常是 `success`、注意是 `warning`、超過上限是 `danger`，各和 `surface-sub` 混成淡色；注意線和上限是兩條 2 px 刻度，下方寫「注意 27」「上限 29」。
- 圓點 14 px，顏色依狀態；狀態另外用文字寫出（正常、⚠ 注意、⚠ 超過上限），不只靠顏色。數值越高越要注意。
- 上方一列：名稱靠左；狀態和數值靠右，數值用等寬字、右對齊在固定寬度的欄（8 個字寬，`--meter-value-width` 可以改）。同一張卡片裡疊好幾個 Meter 時，狀態和數值的右緣都對齊。
- 無障礙：`role="meter"`，`aria-valuetext` 念「28.1 °C，注意，注意 27，上限 29」。

```js
h(UI.Meter, { label: 'B 區進氣溫度', value: 28.1, min: 20, max: 32, warn: 27, limit: 29, unit: '°C', decimals: 1 });
```
