# Term

## 用法

名詞或關係標籤的說明：讀者可能看不懂的詞（例如「translation unit」）和關係標籤（例如「推測（規則）」）。長篇的解釋改連到文件。

```tsx
<p>
  起點經過 2 個 <Term text="一個 `.c` 檔加上它 include 的標頭檔，編譯器一次處理的單位。">translation unit</Term>。
</p>
<p>
  登入後伺服器會寫一個 <Term variant="inline" text="瀏覽器替網站保存的一小段文字。">cookie</Term>。
</p>
```

- 預設在詞的後面加一個小問號，點一下打開；句子裡讀起來不想被打斷時用 `variant="inline"`（灰色虛線）。
- 關係的說明可以加證據那一行程式碼（`code`）和一個動作（`action`，例如「看這一行」）。
- 同一份程式碼或文件反覆出現的詞，用 CodeView 或 Markdown 的 `terms` 自動標，不必一個一個包。
- `text` 裡反引號包住的文字顯示成行內程式碼（InlineCode），不顯示反引號。

## 細節

- 記號：詞的後面加一個小問號，滑過或打開時問號變強調色。文字本身維持周圍的字體和顏色，所以可以放在句子裡，也可以放在 `UI.Tag` 裡。
- 點一次打開，再點一次關閉；右上角也有 ×，按 Esc 或點外面也會關閉。
- 觸控範圍：放在句子裡時不擴大（WCAG 2.2 行內例外）；單獨出現時（Tag 裡、圖例）自動擴大到 48 px，不用另外處理。
- 寬度 600 px 以上：詞的下方浮起小卡，寬 340 px。小卡留在詞所在的區塊裡（最近的卡片、SplitPane 的一邊或主要內容區），往左右移動或變窄來放進去，不蓋到旁邊的面板；區塊比 240 px 窄時才以整個視窗為範圍。小於 600 px：從畫面下方打開，字比較大，按鈕至少 48 px。
- 說明裡的檔案和行號可以用 `refHref`、`onRef`、`isRef` 變成連結（同 CodeText）。
- 內容：標題（預設是詞本身）、一兩句說明（`text`，反引號變行內程式碼）；關係的說明可以加證據那一行程式碼（`code`）和一個動作（`action`，例如「看這一行」）。
- 同一頁同一個詞出現很多次時，每次都可以加；說明要短，長篇的解釋改連到文件。

```js
h('p', null, '起點經過 2 個 ', h(UI.Term, { text: '一個 `.c` 檔加上它 include 的標頭檔，編譯器一次處理的單位。' }, 'translation unit'), '。');

h(
  UI.Tag,
  null,
  h(
    UI.Term,
    {
      title: '推測（規則）',
      text: '經由 `h->post_send` 呼叫，由規則推得，編譯器無法確認。',
      code: ' 74 │ ret = h->post_send(qp, wr, bad_wr);',
      action: { label: '看這一行', onClick: () => openLine('ops.c', 74) },
    },
    '推測（規則）',
  ),
);
```

- 螢幕閱讀器念「說明 caller」：先說按鈕的用途，再念名詞。

## 行內樣式（`variant="inline"`）

句子裡的名詞用行內樣式：不加問號，詞的下方畫灰色虛線，讀起來不打斷句子。

- 外觀：文字顏色不變；虛線是 `--line-strong`，離字 4 px；滑過、打開或鍵盤停在上面時，虛線變強調色。游標是說明游標（help）。
- 滑鼠停在詞上 500 ms 才打開，只是經過不會打開；點一下立刻打開。指標移進小卡時小卡不關閉，離開 150 ms 後關閉。
- 鍵盤：Tab 到詞上立刻打開，Esc 關閉，焦點留在詞上；再按 Tab 進入小卡的動作。
- 觸控（寬度小於 600 px）：點一下從畫面下方打開，和一般 Term 相同。行內不擴大觸控範圍（WCAG 2.2 行內例外）。
- 螢幕閱讀器念「cookie，有說明」；小卡打開時以 `aria-describedby` 連到詞上。
- 小卡和一般 Term 相同（標題、說明、程式碼、動作）。

```js
h(
  'p',
  null,
  '登入後伺服器會寫一個 ',
  h(
    UI.Term,
    { variant: 'inline', text: '瀏覽器替網站保存的一小段文字，之後每次請求都會帶上。', action: { label: '看它出現的地方', onClick: showUses } },
    'cookie',
  ),
  '。',
);
```

同一個詞在很多地方出現時，不必一個一個包：`CodeView` 和 `Markdown` 的 `terms` 會自動找出這些詞並加上行內樣式，預設每個區塊只標第一次（`termsMark: 'all'` 每次都標）。
