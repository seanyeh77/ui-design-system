# Term

名詞或關係標籤的說明：讀者可能看不懂的詞（例如「translation unit」、「LD_PRELOAD 攔截」）和關係標籤（例如「推測（規則）」）。

- 記號：詞的後面加一個小問號，滑過或打開時問號變強調色。文字本身維持周圍的字體和顏色，所以可以放在句子裡，也可以放在 `UI.Tag` 裡。
- 點一次打開，再點一次關閉；右上角也有 ×，按 Esc 或點外面也會關閉。
- 觸控範圍：放在句子裡時不擴大（WCAG 2.2 行內例外）；單獨出現時（Tag 裡、圖例）自動擴大到 48 px，不用另外處理。
- 寬度 600 px 以上：詞的下方浮起小卡，寬 340 px。小卡留在詞所在的區塊裡（最近的卡片、SplitPane 的一邊或主要內容區），往左右移動或變窄來放進去，不蓋到旁邊的面板；區塊比 240 px 窄時才以整個視窗為範圍。小於 600 px：從畫面下方打開，字比較大，按鈕至少 48 px。
- 說明裡的檔案和行號可以用 `refHref`、`onRef`、`isRef` 變成連結（同 CodeText）。
- 內容：標題（預設是詞本身）、一兩句說明（`text`，反引號變行內程式碼）；關係的說明可以加證據那一行程式碼（`code`）和一個動作（`action`，例如「看這一行」）。
- 同一頁同一個詞出現很多次時，每次都可以加；說明要短，長篇的解釋改連到文件。

```js
h('p', null, '起點經過 2 個 ', h(UI.Term, { text: '一個 `.c` 檔加上它 include 的標頭檔，編譯器一次處理的單位。' }, 'translation unit'), '。');

h(
  UI.Tag,
  null,
  h(
    UI.Term,
    {
      title: '推測（規則）',
      text: '經由 `h->post_send` 呼叫，由規則推得，編譯器無法確認。',
      code: ' 74 │ ret = h->post_send(qp, wr, bad_wr);',
      action: { label: '看這一行', onClick: () => openLine('ops.c', 74) },
    },
    '推測（規則）',
  ),
);
```

- 螢幕閱讀器念「說明 caller」：先說按鈕的用途，再念名詞。
