# KpiCard

KPI 卡片，放在 Dashboard 最上方。

- 由上到下：標籤、大數字加單位、迷你折線、變化。
- 數字 31 px、Geist Mono、等寬數字；單位寫在數字後面（人、ms、%）。
- 大數字縮寫只出現在 KPI 卡片：1 萬以上寫成「1,284 萬」（`compact={false}` 可以關掉）。金額用 `format="money"`，顯示成「NT$ 1,284 萬」。
- 數字進場時從 0 數上來（900 ms）。跳動途中用和最終值相同的單位和小數位數，寬度先保留給最終值，所以不會忽寬忽窄。
- 卡片太窄、最終數字放不下時，字級自動從 31 px 縮小，最小 20 px。
- 變化：▲／▼ 加百分比，後面接灰色「較上週」（`compareLabel` 可改）。顏色看好壞：`good` 預設為 `delta > 0`，像錯誤率這種上升是壞事的指標要設 `good={false}`；回應時間下降是好事，設 `good`。
- 百分比的指標，變化用 `deltaUnit="pt"` 顯示「個百分點」。
