# Tabs

同一頁裡切換不同檢視：分段控制。

- 每一項可以加 `count`，顯示在名稱右邊（數字 Geist Mono、次要文字色），後面一定帶單位：`unit` 給整排（例如 `unit: '筆'`），某一項不同時在那一項給 `unit`。結果清單的摘要用這種寫法，例如「全部 6 筆 · 錯誤 4 筆 · 要確認 2 筆」。有 `count` 沒有單位時，開發模式會在主控台提醒。`unit` 也可以傳函式，拿到數字後回傳單位，給有單複數的語言用：`unit: (n) => (n === 1 ? 'item' : 'items')`；傳字串時，數字是 1 而且語言有「1 <單位>」的翻譯（例如 `addMessages('en', { '1 項': '1 item' })`），就用那個。
- 手機上當作摘要使用時，各項平均分配寬度，不換行。
- 分頁的字一律不換行；整排比外框寬時改成左右捲動，選中的底塊跟著捲，分頁不會互相重疊。還有分頁的那一側邊緣淡出（40 px），看得出可以往那邊捲；選中的分頁自動捲進畫面。

- `surface-sub` 灰底軌道，選中的是浮起的 `surface` 白塊，圓角 `radius-md` 10 px。
- 切換動畫：水滴。靠近目標的一端先移動（120 ms），另一端慢 2.2 倍才跟上（440 ms），移動中略為變細，到位後恢復；全程是同一塊，邊緣清晰。
- 內容切換：新內容的卡片依序浮起（外層加 `ui-rise-in`，並在切換時換 `key` 重新掛載）。

## 無障礙

- 名稱和數字之間有空格，念成「全部 26 個」。
- ← → 切換分頁；按住 Alt、⌘（Meta）或 Ctrl 時不處理，留給瀏覽器（例如 Alt + ← 回上一頁）。
- 切換後焦點留在選中的分頁；分頁列重新產生、原本有焦點的分頁不見時，焦點移到選中的分頁。live region 念出新分頁的名稱和數字。
