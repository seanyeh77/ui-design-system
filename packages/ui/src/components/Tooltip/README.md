# Tooltip

提示：滑過或用鍵盤移到元素上時出現的短文字。

- 深色（`ink` 底、`bg` 字），圓角 `radius-chip`，13 px 粗體。
- 預設在元素上方，有指向元素的箭頭；上方放不下時改到下方。
- 延遲 0 ms：滑過或 focus 立刻出現；移開、失焦或按 Esc 消失。
- 出現動畫：從箭頭那一側放大，220 ms，稍微回彈。減少動態效果時只淡入。
- 長文字（例如表格裡被截掉的格子）設 `wrap`：最寬 360 px、一般粗細、自動換行。`disabled` 暫時關掉而不卸載觸發元素。
- IconButton 會自動用 `label` 加上 Tooltip；其他元素用 `<Tooltip label>` 包起來。只放短文字，不放按鈕或連結。
