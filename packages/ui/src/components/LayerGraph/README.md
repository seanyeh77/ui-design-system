# LayerGraph

架構圖：項目（元件、服務、模組）分層排列，箭頭表示關係。給資料就會自己排版和畫線，不用自己畫 SVG。

- 分層：`layer` 0 在最上面，同一層由左到右照資料順序，置中排列。
- repo 外的項目（`external: true`，例如被追蹤的程式、外部函式庫）：畫在所有分層的上方，自成一排；虛線外框（1.5 px `line-strong`）、白底、沒有左側色條，名稱下方寫「repo 外」（`externalLabel`），不顯示大小條（`size` 不使用），不算進任何分層。連到其他項目的線和一般的線一樣畫，`inferred`、`label` 都適用；可以和其他方框一樣用 `selected`、`onSelect` 選取。清單檢視也列出它，寫「名稱，repo 外」。清單裡的分隔標點（「，」「：」「（推測）」）經過 `UI.t()`，英文介面是 `, `、`: `、` (Inferred)`。
- 共用項目（`shared: true`，幾乎每個項目都會用到的，例如 `src/common`）不畫在分層裡，改在圖的下方排成一排小方框，外觀和圖上的方框一樣，數量多時換行；方框裡第二行預設寫「N 個項目使用，共 M 次」（`sharedMeta`，`{a}` 是項目數、`{b}` 是次數）。項目數和次數包含其他共用項目的使用，和清單檢視列出的線一致；選取一個共用項目時，用到它或它用到的其他共用項目不變淡。標題預設「共用項目」（`sharedLabel`）。
- 共用項目和方框一樣可以選，用同一組 `selected`、`onSelect`（傳共用項目的 `id`）。選到時小方框用選取樣式；用到它的方框維持原樣，右上角寫「使用 N 次」（`useLabel`，`{n}` 是 `edges` 裡指向它的 `count` 加總），其他方框和所有線淡到 40%。選一般方框時，它沒用到的共用項目變淡。
- 方框：淡灰底，左側一條灰色色條；第一行是名稱（Geist Mono），第二行是大小長條和文字，長條長度和最大的項目相比。大小給 `size`（函式數、檔案數、端點數），文字用 `sizeLabel` 換成專案的單位，預設「{n} 個項目」（英文「1 item」「2 items」）。`sizeLabel` 也可以是數量的函式，給隨數量變化的字：`(n) => n === 1 ? '1 function' : `${n} functions``。
- 線：直角轉彎、轉角是圓的，每條線接在方框上不同的位置。線的粗細依次數（`count`），全部灰色。推測的關係（`inferred`）是細虛線，箭頭旁寫 `label`。專案自己宣告的關係（`declared`，例如設定檔 rules.json 宣告的 ring 通道）是長短交替的虛線（1.5 px），標籤和推測的一樣一直顯示；清單裡寫「（宣告）」，`declaredLabel` 換掉這個詞。有依據但不是編譯器看到的呼叫，不要畫成推測。一個方框收到兩條以上有標籤的線（推測的線或有 `label` 的線）時，這幾條線在兩層之間各走一段自己的高度（間隔 28 px）再轉彎，標籤緊貼在自己轉彎的地方，寫在轉角的左側或右側；高度順序和左右在所有排法中挑沒有線穿過標籤的一種，標籤一行寫完不截斷，需要時圖往右加寬，超出左邊時整張圖往右移。只有一條時標籤寫在箭頭右側；仍會碰到已經放好的標籤或其他箭頭時往上移一行（18 px）。標籤不壓到任何線（包括自己的線）和方框：在原本那側找不到位置時改放箭頭另一側，再不行就換成 2 到 4 行，再不行就把箭頭上方兩層之間的空隙加高。標籤不會超出圖的左右邊界：放不下時改放另一側。選取時的「N 次」（`countLabel`）也一樣；`countLabel` 和 `sizeLabel` 一樣可以是字串或數量的函式，預設英文「1 call」「2 calls」。
- 往上的線的標籤先沿著自己的線找位置，離起點越近越好，而且要離自己的線比離其他任何一條線都近，讀者不會以為是旁邊那條線的標籤；找不到才放在線道旁。
- 每個標籤都要讀得出是哪一條線的：位置要離自己的線比離其他任何線近 4 px 以上，也離其他線至少 8 px。找不到這種位置時，標籤改成線上的編號（20 px 深色圓點，數字用等寬字），圖的下方依編號列出每一條的完整文字；滑過或選取這條線時，完整文字也浮在圖上（實心底色，蓋在線上）。編號不佔標籤的位置，螢幕閱讀器照樣從線本身念出完整文字；往上的線的線道在所有方框外側，就算標籤寫在最左邊讓方框往右移，線道也跟著移，不會從方框後面穿過。
- 標籤和標籤之間上下至少留 4 px，不會貼在一起。找不到不碰到任何線的位置時，這個標籤等其他標籤都放好再放，蓋在線上時用實心底色，線在標籤處中斷，不會從字中間穿過。換行時逗號（`,`、`，`）不放在行首。
- 原本的位置都被擋住時（線多、方框擠在一起），標籤沿著自己的線找位置：直的一段的左右兩側、橫的一段的上下，每 6 px 試一次，一行或換行，選不壓到任何線、方框、箭頭和其他標籤、離箭頭最近的位置。還找不到時先加高兩層之間的空隙，再把同一層方框之間的距離加大（每次 24 px，最多 120 px），直到沒有標籤壓到線；圖因此變寬時，照下面的規則先縮窄方框、再縮小、最後左右捲動。
- 從一個方框出去的線分散在整個方框寬度（離兩邊各 16 px），讓線和線之間有放標籤的空間；只有一條時從中間出去。
- 同一層兩個方框之間的線：從來源的下緣出去，在這一排下方的空隙裡橫過去，從目標的下緣進入，箭頭朝上；不會穿過方框。最後一排的這種線，圖的下方多留空間。
- 兩條以上的線標籤文字一樣時（例如兩個方框都「執行 ibmon」），每條的標籤前面加上來源：「來自 src/cli，經由 execvp 傳資料」，英文「From src/cli, passes data …」；圖上的線和清單都一樣。
- 往上一層的線（`to` 的 `layer` 比 `from` 小，例如資料經由共用元件交回上層）：從來源方框的側邊出發，沿著圖的一側往上，從目標方框的側邊進入，箭頭指向方框。目標是該層最左邊的方框時走左側，否則走右側；目標在一層的中間（兩邊都有方框）時，從右側通道繞到目標下方，從下緣進入。每條往上的線有自己的通道（間隔 12 px），圖往那一側加寬通道的寬度；標籤放在線旁邊（左側通道的右邊、右側通道的左邊），在兩層之間的空隙，不另外加寬。標籤不壓到方框、其他標籤和任何線（同一對方框之間往下的線也一樣），碰到時以 18 px 為單位往上、再往下找位置；一行放不下時換成 2 到 4 行（寬度變窄，放得進通道和下一條線之間），還是沒有位置就把那個空隙加高。
- 換行和加高：在中文字之間或空格換行，不拆開 `code`、英文字、數字和後面的單位（「3 次」），不把右括號或標點放在行首。空隙每次加高 24 px，最多 144 px；加到 144 px 還是沒有位置時，空隙回到原本的 56 px，標籤照舊蓋在線上（標籤有白底）；只有在這個空隙放不下、會壓到方框或其他標籤時，才再加高到剛好放得下（一樣最多 144 px）。往下的線的標籤一律留在箭頭正上方那個空隙，不越過上面的方框。標籤上下和其他標籤至少相隔 4 px。選取、滑過樣式和鍵盤操作和其他線一樣。
- 線上的文字預設全部顯示。「圖／清單」左邊有一個開關（Switch），旁邊寫「線上文字」（英文 Line labels）：開著時全部顯示，關掉改成滑過才顯示。點旁邊的文字也會切換；整排至少 48 px 高。畫面上看開關就知道狀態，手機沒有提示框也不會把名稱讀成動作。需要更精簡的工具列時給 `labelToggle="icon"`，改用原本的標籤圖示按鈕（40 px，沒有外框）：切換按鈕，名稱固定「顯示線上文字」，按下時（強調淺底、實心圖示，`aria-pressed="true"`）表示正在顯示。只有圖上有推測或宣告的線時才出現，切到清單時隱藏；`labelToggle={false}` 拿掉它。使用者的選擇記在 `localStorage`（鍵名 `ui-lg-labels:` 加 `scrollKey`，預設是方框的 id），下次開同一張圖時維持；讀寫失敗時照常切換，只是不記住。`edgeLabels` 是一開始的狀態：給 `edgeLabels="hover"` 時一開始隱藏，滑鼠移到線或標籤上、用鍵盤移到線上（需要 `onSelectEdge`）、選到這條線，或選到它兩端的方框時，才顯示那一條的標籤。標籤的位置照樣保留，顯示時不會推動版面。沒有 `onSelectEdge` 時，線只能滑過，不能點也不能用鍵盤移到；觸控螢幕沒有滑過，要看標籤就選方框，或給 `onSelectEdge` 讓線可以點。螢幕閱讀器照樣念出每條線的標籤。
- 手機上圖比外框寬時（改成左右捲動），一開始捲到方框的最左邊（左側只有標籤的空白不算），最左邊的方框完整看得到；一開始就有選取的方框時捲到那個方框。之後選取的方框不在畫面內時，捲到剛好看得到它。回到同一張圖時維持上次捲動的位置。
- 短標籤（`tag`，例如「可修改」「受保護」）：在名稱右邊同一行，12 px、次要文字色的小標籤。方框變窄時名稱先用「…」截斷，標籤一定完整，所以只寫幾個字。窄到有名稱只剩不到 8 個字時（例如手機），整張圖的標籤都改到名稱下一行，方框從 60 px 加高到 76 px，名稱可以用整個寬度。`tagTone: 'warning'` 改用 warning 文字色與淺底，前面加鎖頭圖示，用在不能改的項目。清單也在名稱後面顯示標籤，螢幕閱讀器念「名稱 標籤 大小」。不要把標示接在 `name` 後面：方框變窄時會和名稱一起被截掉。
- `toolbar`：頁面自己的控制項（例如「依元件／依檔案」Tabs），放在「圖／清單」同一列的左邊，兩個開關不會分在兩列。窄寬度時這一列換行。
- 「圖／清單」切換（右上角，`listView={false}` 關掉）：清單列出每個方框（名稱，大小）和每條線（「A → B：標籤」），可以點，點了和點方框或線一樣選取。線的整行都是按鈕，畫面寫「A → B：說明」，念「A 到 B：說明」，同起訖的幾條線各有不同的名稱。每一條關係都能選，包括連到共用項目、圖上沒有畫成線的那些：有 `onSelectEdge` 時點一下、Enter 或空白鍵都會呼叫它，和點圖上的線一樣；選中的那一行 `aria-pressed="true"`、淺色底，再按一次取消。方框名稱有底線，說明是一般文字色。標題預設「項目」和「關係」（`listLabels`）。切回圖時保持選取。
- 捲動位置會記住：同一張圖（`scrollKey`，預設是方框的 id）切到別的區塊或清單再回來，回到上次的位置。
- 螢幕閱讀器：方框是按鈕，念名稱和大小；可以選的線也是按鈕，放在 `role="group"`（不是圖片）裡，念「起點 到 終點，標籤」（不用「→」：螢幕閱讀器會念成「右箭頭」或略過）；畫面上的標籤不重複念。
- 選取（`selected`、`onSelect`）：點方框選取，再點一次取消。選取時相關的方框和線維持原樣、線變強調色並在箭頭旁寫「N 次」，其他淡到 40%。
- 選線（`selectedEdge`、`onSelectEdge`，和 `selected`、`onSelect` 一樣是受控的）：有傳 `onSelectEdge` 時線才能點。點線或線上的標籤選取，再點一次同一條線或點圖的空白處取消（`null`）。選到的線變粗並用強調色，箭頭用強調色，標籤用強調文字色；線兩端的方框維持原樣，其他方框和線淡到 40%。線和方框一次只選一個：選線會清掉方框的選取，選方框會清掉線的選取。
  - 每條線的 `id` 預設是 `` `${from}->${to}` ``，同一對方框之間有兩條線時要自己給 `id`。
  - 點擊範圍：每條線上疊一條看不見、12 px 寬的路徑；有標籤的線，標籤也能點，觸控螢幕上標籤的點擊範圍至少 48 px。沒有標籤的線在手機上比較難點到，需要時改用標籤或鍵盤。
  - 滑鼠移到線或標籤上，游標變成手指，線和箭頭變深、線加粗 2 px，標籤加底線。
  - 鍵盤：線排在方框之後，Tab 依序移到每條線，Enter 或 Space 選取，Escape 取消。焦點樣式和方框一樣用 `focus-ring` 色。`aria-label` 是「起點 到 終點，標籤」（標籤裡的反引號拿掉，螢幕閱讀器不會唸出來）或「起點 到 終點，N 次」；英文是「from to to」，選到時 `aria-pressed="true"`。
  - 細節面板由 app 自己畫，`LayerGraph` 只負責選線並回報 `id`。
- 層與層之間 56 px。repo 外的方框自成一排時，其他方框變窄它也維持原本的寬度（不超過圖寬），名稱不被截斷。圖比外框寬時，先把方框變窄到剛好放得下（最窄 120 px），方框之間的間距從 40 px 縮成 24 px，字的大小不變，太長的名稱用「…」；還是放不下時整張圖等比縮小到外框的寬度，最小 0.75 倍。之後標籤或線的空間讓圖變寬時，縮小的比例跟著重算，不會因此改成捲動。縮小後方框和標籤在觸控螢幕上的點擊範圍仍是 48 px（反向放大 `::after`）。要縮得比 0.75 倍更小時改回左右捲動，方框回到原本的寬度和間距（`nodeWidth`，預設 200 px），名稱完整，不縮小：右邊還有內容時右緣有漸層；圖的下方靠右有提示（觸控螢幕寫「→ 左右滑動」、滑鼠寫「→ 向右捲動」，次要文字色，不壓在方框上），第一次捲動後隱藏，但保留位置，下方內容不會跳動。
- 圖例預設放在下方，只列出圖上有的線：有一般的線才寫「次數越多線越粗」，有推測的線才寫「推測的關係」，有宣告的線才寫「專案宣告的關係」（`declaredLegend` 換掉、`declaredText` 加說明），沒有線就不顯示；`inferredText` 是推測的說明（Term），`inferredLabel` 換掉「推測」這個詞。
- 放在卡片上。直接放在頁面底色上時，外層加 `style: { '--ui-graph-bg': 'var(--bg)' }`。

```tsx
<LayerGraph
  nodes={[
    { id: 'web', name: 'web', layer: 0, size: 91 },
    { id: 'api', name: 'api', layer: 1, size: 114 },
    { id: 'common', name: 'common', shared: true },
  ]}
  edges={[
    { from: 'web', to: 'api', count: 18 },
    { from: 'web', to: 'common', count: 6 },
  ]}
  sizeLabel="{n} 個端點"
  countLabel="{n} 次請求"
  selected={selected}
  onSelect={setSelected}
/>
```

點線在旁邊顯示細節：

```tsx
const [box, setBox] = useState<string | null>(null);
const [edge, setEdge] = useState<string | null>(null);

<Grid columns={2}>
  <Card>
    <LayerGraph
      nodes={nodes}
      edges={[
        { id: 'shm', from: 'ibmon', to: 'lib', inferred: true, label: '環境變數 `IBTRACE_SHM`' },
        { from: 'cli', to: 'lib', count: 7 },
      ]}
      selected={box}
      onSelect={setBox}
      selectedEdge={edge}
      onSelectEdge={setEdge}
    />
  </Card>
  <Card title="關係">{edge ? <DetailList items={details[edge]} /> : '選一條線查看細節。'}</Card>
</Grid>;
```

從舊版升級：`fns` 改名 `size`，原本寫死的「N 個函式」「被 N 個元件呼叫」改用 `sizeLabel`、`sharedMeta` 傳入。
